CUSTOMIZATION:
────────────────

Easy to modify:

1. Algorithm parameters (src/main.cpp):
   - Window size (7 → smaller for speed, larger for quality)
   - Det threshold (1e-3 → adjust sensitivity)
   - Max flow (20 → color brightness scale)

2. Camera settings (config/camera_ubuntu.yaml):
   - Resolution (1280×720 → change for FPS)
   - FPS (30 → target frame rate)
   - Source (0 → device index or URL)

3. Build options (CMakeLists.txt):
   - Compiler flags (add -march=native)
   - Build type (Release vs Debug)

4. Display options (src/main.cpp):
   - Window size/position
   - FPS display format
   - Text overlays
